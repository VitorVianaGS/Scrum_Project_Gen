# 📚 Scrum Project Gen | Biblioteca Pública

Projeto de análise de dados voltado à gestão de uma biblioteca pública, com foco na identificação de padrões de empréstimos, utilização do acervo e necessidades dos usuários.

## 🎯 Objetivo

Analisar os dados da biblioteca para auxiliar na gestão do acervo, compreender o perfil dos leitores e propor melhorias nos serviços oferecidos à comunidade.

## 📊 Escopo do projeto

- Levantamento de informações sobre o acervo.
- Análise de empréstimos e devoluções.
- Identificação dos livros e gêneros mais procurados.
- Análise do perfil e da frequência dos usuários.
- Limpeza e tratamento dos dados.
- Construção de gráficos e indicadores.
- Elaboração de propostas de melhoria.

## 🛠️ Ferramentas e tecnologias

- GitHub
- GitHub Projects
- Python
- Jupyter Notebook
- Pandas
- Matplotlib

## 📋 Metodologia

Utilização do framework Scrum para planejamento e execução das atividades, com acompanhamento das tarefas por meio de um quadro Kanban no GitHub Projects.
